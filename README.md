# ביוגרפיות

תוסף לאוצריא. הקוד עצמו נמצא תחת `src/`, וקובץ ה-`.otzplugin` נבנה ממנו.

## פרסום גרסה חדשה

הפרסום אוטומטי. כל מה שצריך הוא לעדכן את `version` בתוך `src/manifest.json`
ולדחוף ל-`main`:

```bash
git add -A
git commit -m "תיאור השינוי"
git push origin main
```

מכאן [הריצה](../../actions) בונה את התוסף, מוציאה תג `vX.Y.Z` ו-GitHub Release,
ומעדכנת את החנות ב-otzaria.org. אם הגרסה ב-manifest לא השתנתה — הריצה מדלגת
בשקט, כי החנות דוחה ממילא העלאה של גרסה שכבר קיימת.

מספור הגרסאות: הספרה האחרונה עולה עד 9 ואז מתגלגלת — `1.0.9` הופך ל-`1.1.0`.

## בנייה מקומית

```powershell
.\build.ps1
```

נוצר `otzaria-biographies.otzplugin` בשורש. באוצריא: **הגדרות → ניהול תוספים → התקנה מקובץ**.

## סודות שהריצה צריכה

| שם | תפקיד |
|----|-------|
| `OTZARIA_USER` | שם המשתמש / האימייל בחשבון otzaria.org |
| `OTZARIA_PASSWORD` | הסיסמה לאותו חשבון |
| `OTZARIA_PLUGIN_ID` | מזהה התוסף בחנות (ה-`id` מ-`/api/plugins`, לא ה-`id` שבמניפסט) |

בלי שלושתם שלב הפרסום לחנות מדולג, וה-Release עדיין נוצר — כך שתמיד אפשר
להתקין ידנית מהקובץ.

## נתוני "ראשונים ואחרונים"

הנתונים תחת `src/data/rabbis/` נוצרים מקבצי המקור (CSV של אוצר הספר העברי, "שנות דור", יארצייטים,
הרשימה הכרונולוגית של בר-אילן, אוצרות התורה) ע"י הסקריפט `tools/build_rabbis.py`. אין לערוך אותם ידנית.

```powershell
python -I tools/build_rabbis.py --src <תיקיית הקבצים> --report build_report.txt
```

מקור נוסף: תוסף "יומא דהילולא" (v1.0.1) — כל 631 הרבנים שבו נכנסים כמקור `h` (איחוד לרשומות קיימות לפי שם + שנים/יום פטירה, והשאר נוספים כרשומות חדשות; כולל יום ושנת פטירה, מקומות, רבנות, ספרים, תקופה `e`, קואורדינטות `co`), ו-26 הישיבות נשמרות כמות שהן ב-`src/data/yeshivot.js` (`window.YESHIVOT`). קישורים חיצוניים (`bioUrl`) אינם נשמרים. הנתיב לקובץ התוסף: `--yoma <קובץ>` (`-` לדילוג); תיקיית פלט חלופית: `--out`.

כלל שיוך ספרים (דיוק לפני כיסוי): ברשימה הכרונולוגית של בר-אילן ובשורות "בר-אילן" של "שנות דור" רק הפריט שבשורת הכותרת / הכותר הראשון משויך למחבר בוודאות. פריטים עוקבים נשמרים רק אם בכותר מופיע טוקן משם המחבר או כינויו (למשל "רש"י (שו"ת)" אצל רש"י), או אם הכותר זהה לספר מאומת של אותו מחבר; אחרת הם נזרקים (כך "אוצר ההלכה" או "תוספות" לא יתווספו בטעות למחבר הקודם ברשימה). שורות מפורטות של "שנות דור", עמודת "חיבור" ביארצייטים וספרי "יומא דהילולא" נשארים כי המחבר מצוין בהם במפורש.

אימות לפי קטלוגים: ספר ממתין (פריט עוקב ברשימה מצטברת) משוחזר גם בלי טוקן בכותר אם בקטלוג כלשהו (ספריית אוצריא `seforim.db`, קטלוג היברו-בוקס/אוצר החכמה, ומאגר הביוגרפיות המובנה של אוצריא) יש ספר בכותר תואם (התאמת מילים עבריות, כולל "X על שולחן ערוך...") שמחברו תואם לשם הרב (שני טוקני שם, או טוקן נדיר עם שנות חיים/כינוי תואמים). הקטלוגים נקראים בקריאה בלבד בזמן הבנייה (`--seforim-db`, `--hb-db`, `--bios-gz`, `--no-catalog`) ושום טקסט מהם לא מועתק לתוצר, מלבד `src/data/lib-authors.js` (כותר מנורמל -> שמות מחברים מספריית אוצריא, לממשק הבחירה). מאגר הביוגרפיות של אוצריא (`biographies-app.json.gz`) מורשה AGPL-3.0 בתנאי ייחוס ל-abaye: הוא משמש כאן כראיית אימות בלבד, ואנו מייחסים אותו למחברו abaye.

האינדקס (`rb-index.js`) נטען עם פתיחת הטאב, וקובצי הביוגרפיה (`rb-N.js`, חלוקה לפי אות) נטענים לפי צורך.
